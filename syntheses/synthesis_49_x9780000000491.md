# 49. Reverse Engineering for Beginners

Yurichev's "Reverse Engineering for Beginners" (RE4B) is a free, open-source, ~1000-page from-zero manual. Its real subject is not exploitation but the inverse of compilation: build such a deep, imprinted mapping between C/C++ source and the assembly a compiler emits that any disassembly back-projects to recognizable structure. The stated method (1.1) is literally compile-look-repeat: write tiny C, read the compiler output at multiple optimization levels (debug vs release matters, optimized code deletes whole source lines), do it enough that the patterns are automatic.

Chapter 1 (Code patterns, the bulk of the book) walks every fundamental construct across four ISAs in parallel: x86, x64, ARM (ARM/Thumb/Thumb-2/ARM64), and MIPS. Empty function, returning a value, Hello-World, function prologue/epilogue, the stack (why it grows backwards, typical layout, noise), printf/scanf argument passing, pointers, GOTO/dead code, conditional jumps, switch (small-N if-chains vs jump tables), loops, strings, arithmetic-to-shift substitution, the FPU and IEEE 754, arrays (including the buffer-overflow and stack-canary section 1.20, the "miners' canary" random stack value checked in the epilogue), bit manipulation, the linear congruential PRNG, structures, unions, function pointers, 64-bit-in-32-bit, and SIMD. Chapter 2 (Important fundamentals) covers integral types, signed/two's-complement, AND/OR/XOR identities, population count, endianness (big/little/bi-endian and conversion), memory, branch predictors, and one-way hash functions. Chapter 3 (advanced examples) does strstr, Fibonacci, CRC32, network-address/netmask calculation, Duff's device, division-by-multiplication, atoi, the format-string exploit (3.14.4), incorrectly-disassembled code and how random noise disassembles, and Chapter 3.18 obfuscation (text-string encoding, executable-code obfuscation, VM/pseudo-code, anti-debugging). Chapter 4 reverses Java/JVM bytecode (returning values, loops, switch, strings, classes, exceptions, simple patching).

The three chapters NuClide reaches for most:

Chapter 5, "Finding important/interesting stuff in the code," is the attribution and triage core. 5.1 is a compiler/toolchain fingerprint table: MSVC versions mapped to msvcr*/msvcp* DLL imports and the ? name-mangling prefix; GCC's _Z mangling, Cygwin/MinGW DLLs; Intel Fortran's for_ prefix and libifcoremd.dll; Watcom W mangling; Borland. 5.4 runs strings (OpenSSH sshd example), reads error/debug messages (Oracle ksdwrt), and 5.4.4 hunts suspicious magic strings, with the canonical TP-Link WR740 backdoor URL (userRpmNatDebugRpm26525557) that fit no RFC, library, or error convention and was not googleable until disclosure. 5.5 uses assert() conditions and file names to recover variable/struct names and identify open-source libraries. 5.6 recognizes constants and magic numbers: MD5 init values (0x67452301...), CRC16/CRC32 polynomials and tables, file headers (MZ, MThd), date-shaped constants (Stuxnet 19790509, UFS2 0x19540119), and 0xAAAAAAAA/0x55555555. 5.10 covers memory-snapshot comparison.

Chapter 8 (Case studies) is the applied payoff: dongle emulation across MacOS/PowerPC, SCO OpenServer, and MS-DOS (8.5); the QR9 amateur crypto-algorithm (8.6); and Encrypted database case #1 (8.7), the schema-only blob-triage method we use directly: recognize base64 by alphabet, compute Shannon-entropy variance to detect compression/encryption, infer compressed-vs-encrypted from missing headers and block-size divisibility (DES 8 / AES 16), then spot CryptoPP strings and AES helper instructions (AESENC, AESKEYGENASSIST). Also SAP 6.0 password-checking functions (8.10.2), Oracle RDBMS internals (8.11), executable-cryptor breaking (8.9), and the EICAR test file. Appendix 9.2 generalizes entropy analysis: slice a file into 4K blocks, plot per-block entropy in Mathematica calibrated to Linux ent's bits-per-byte, and read the structure of an unknown binary (the GeoIP example separates table region from text blob).

Caveats: tooling and ISA framing are dated (32-bit EIP-era examples, pre-Ghidra), and chapters 1-4 are a teaching grind, not a reference. Reach here for the binary-reading foundation and Chapters 5/8/9, not for a modern exploit recipe.
