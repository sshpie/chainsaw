# NLP for Software Engineering

ISBN: 9781394272433  |  Book #21

## One-liner
A 31-chapter edited Wiley/Scrivener survey volume that, despite its title, is a broad applied-ML-and-cybersecurity anthology (cloud zero-day defense, vulnerability prioritization, malware, IoT IDS, medical imaging, web mining, sentiment, rumor detection, blockchain) where NLP is one thread among many.

## Thesis
The book argues that machine learning, deep learning, ensemble methods, and NLP can be applied across an extremely wide range of software-engineering and security problems, from detecting zero-day cloud attacks and prioritizing CVSS-scored vulnerabilities to diagnosing Alzheimer's from MRI and detecting rumors on Twitter. Its real center of gravity for a security reader is the cluster of chapters (23 through 26) treating cloud-provider security posture, AHP-based vulnerability prioritization that critiques CVSS as a standalone metric, ensemble-ML zero-day attack detection on CIC datasets, and graph-neural-network rumor detection. The recurring methodological claim is that combining multiple classifiers (bagging/boosting/stacking) and engineering the right features beats any single model, and that domain-specific datasets plus careful preprocessing determine outcomes more than model choice. The volume is a state-of-survey rather than a unified original contribution; most chapters are literature-review-heavy with a proposed pipeline appended.

## Structure
### Security and IoT cluster (Ch1-2, Ch5-6, Ch16-19)
IoT intrusion detection (HIDS/NIDS/hybrid IDS, NSL-KDD, fuzzy logic, GA, HNB), web-application vulnerability identification (XML injection, WRAPS, SQLProb, CVSS/NVD), Android mobile-malware detection (Drebin dataset, CANDYMAN, FCSCNN, SVM/CNN/RNN), spam filtering in OSNs (content-based vs identity-based, RIPPER, Bayesian filters, SVM classifier), and cyber-security technique survey (APTs, cryptojacking, spear phishing, kill-chain phases). Establishes the ML-for-defense framing.

### Medical imaging and clinical-ML cluster (Ch3-4, Ch12-13, Ch15, Ch29)
Prostate cancer detection (MPMRI, PI-RADS, K-means, FCM, GLCM, AdaBoost, RF/KNN), general cancer classification (SVM, SOM, ANN backprop, SEER/Wisconsin datasets), brain-tumor classification (MRI denoising with Gaussian/median/Wiener filters, glioma/meningioma), pancreatic adenocarcinoma (dynGENIE3, miRNA biomarkers, MSD dataset), and Alzheimer's detection (CT/MRI, filter/wrapper/intrinsic feature selection, DT/RF/SVM/VGG16, deep transfer learning on Mel spectrograms). Demonstrates the same ML pipeline transplanted to healthcare.

### Core security-research cluster (Ch23-26)
The most curriculum-relevant block: Ch23 reviews security features of major CSPs (AWS, Azure, GCP, IBM, Alibaba, Salesforce) against a real-breach table (S3, Cosmos DB, LockBit/Accenture, Kaseya, Cognyte, KA-SAT/Ukraine); Ch24 applies the Analytical Hierarchy Process (MCDM, pairwise comparison matrix, consistency ratio) to prioritize cloud vulnerabilities and explicitly critiques CVSS as insufficient alone; Ch25 builds the APEML ensemble model to detect/mitigate zero-day attacks across six CIC datasets with non-monotonic belief updating and ASR/Exploit-Guard mitigations; Ch26 builds the TTRD graph-neural-network rumor detector fusing BERT, Word2Vec, tweep-tendency encoding and propagation-graph dynamics.

### NLP and language-technology cluster (Ch7-11, Ch20-22, Ch28)
Indic-language spellcheckers and grammar checkers (rule/statistical/DL/RL approaches across Assamese, Bengali, Hindi, Tamil, Telugu, Urdu, etc.), Gujarati Ghazal chanda (meter) identification with a cross-platform app and Gujarati SentiWordNet, text-mining techniques (TF-IDF, VSM, clustering, summarization), NL2SQL automated query processing (SQLizer, SEQ2TREE, SQLNet, Seq2SQL, DBPal, NSP), soft-computing NLP (SVM, Bayesian nets, CRF, MaxEnt, ANN), sentiment analysis (VADER, document/sentence/aspect levels), and emotion detection via text classification (ML/DL/ensemble, LSTM/Nested-LSTM, EEG/audio MFCC).

### Web mining, blockchain, maritime, and methodology cluster (Ch14, Ch27, Ch30-31)
Software fault prediction with optimized ML (TSVM, firefly, ACO, cost-sensitive feature selection on NASA/PROMISE data), web usage/content/structure mining and intelligent pattern discovery from server logs (graph traversal, Jaccard similarity, sequential patterns), blockchain-plus-NLP integration (Ethereum smart contracts, tokenization, decentralized translation, plagiarism/text authentication, 25.3% CAGR market claim), a netnographic literature review of maritime cyber threats (criminal-flows framework, oceanic crime categorization, IMO, 900% attack increase), and a research-methodology/threat-management review (QLR/QTR/MMR, STRIDE model, Zotero/SPSS/Tableau tooling).

## Core ideas
- Ensemble learning (bagging, boosting, stacking) is the book's most repeated prescription: nearly every prediction chapter concludes that combining classifiers beats any single model, exemplified by the APEML zero-day model and the FAU-Aibo/cross-corpus emotion work.
- CVSS is treated as necessary but insufficient for vulnerability prioritization; Ch24 builds an Analytical Hierarchy Process (AHP) multi-criteria decision pipeline with pairwise comparison matrices and a consistency ratio to rank cloud security criteria instead of relying on a single severity score.
- Zero-day defense is framed as a detection problem solvable with supervised ML over labeled attack datasets, with the explicit caveat that signature-based detection fails on metamorphic and polymorphic malware, pushing the field toward statistics-, behavior-, and hybrid-based detection.
- Real breaches are used as evidence rather than hypotheticals: the cloud chapters cite AWS S3 exposure, Azure Cosmos DB, LockBit hitting Accenture, the Kaseya supply-chain attack, Cognyte, and the KA-SAT/Ukraine satellite-modem incident tied to Russia's invasion.
- Feature engineering and dataset preprocessing matter more than model choice; chapters repeatedly show Correlation Feature Selection (CFS), PCA, information gain, and Pearson correlation cutting dimensionality before any classifier runs.
- Graph neural networks are positioned as the next step for social-context problems: the TTRD rumor detector models propagation graphs and tweep-tendency, fusing BERT and Word2Vec embeddings with network-dynamics extraction rather than treating text in isolation.
- Cloud security is governed by the shared-responsibility model across IaaS/PaaS/SaaS, with NIST as the reference authority and zero-trust as the recommended posture; the CSP comparison table is the practical artifact.
- NLP is decomposed consistently into rule-based, statistical, and neural/deep-learning approaches, a taxonomy reused verbatim across the spellchecker, sentiment, and emotion chapters.
- Medical and security applications run the identical ML pipeline (preprocess, extract features, select features, classify, evaluate), showing the editors' thesis that the methodology generalizes across domains regardless of subject matter.
- The same author network (Romil Rawat and co-editors) recurs throughout citations and companion volumes (Quantum Computing in Cybersecurity, Robotic Process Automation, Autonomous Vehicles), revealing this as one node in a connected Scrivener anthology series.
- STRIDE threat modeling and a research-methodology framework (QLR/QTR/MMR, systematic/scoping/meta-analysis literature reviews) are offered as the governance layer for IT threat management in the closing chapter.
- Maritime/oceanic cybercrime is treated netnographically (online-community observation), categorizing crime as mutation, forced, military, and atmosphere-disturbing, and citing a claimed 900% rise in maritime cyber-attacks over three years.

## Techniques and methods
- AHP (Analytical Hierarchy Process) for cloud vulnerability prioritization: build a pairwise comparison matrix of security criteria, compute criteria weights, derive a consistency index and consistency ratio against a random index (RI), then rank vulnerabilities into a priority matrix (Ch24).
- APEML (Adaptive Predictive Ensemble Machine Learning) zero-day pipeline: data retrieval/collection/preprocessing (CSV) -> feature extraction engineering -> ensemble learning (SVM, RF, NB, LR, NN, decision-tree variants) over six datasets -> update predictive belief set via non-monotonic reasoning -> evaluate with accuracy/precision/recall/F1/AUC/ROC and confusion matrices (Ch25).
- TTRD (Tweep Tendency-aware Rumors news Detection): encode tweep tendency, extract network dynamics, integrate extracted information via dot-product attention and pooling, fuse BERT + Word2Vec embeddings over a propagation graph with GraphSAGE-style GNN, classify with stochastic gradient descent (Ch26).
- Standard supervised ML evaluation harness reused book-wide: train/test split (typically 70-80/20-30), confusion matrix, accuracy/precision/recall/specificity/sensitivity/F1, ROC/AUC.
- Feature selection family: filter (CFS, information gain, entropy, symmetric uncertainty), wrapper (iterative prediction-error subset search), and intrinsic (decision-tree-embedded) approaches; plus PCA and Pearson correlation for dimensionality reduction.
- Decision-tree algorithm taxonomy: ID3, C4.5, C5.0, CART, CHAID with Gini index, gain ratio, information gain, and pre/post pruning.
- Image preprocessing chain for medical ML: Gaussian/mean/median/bilateral/Wiener filtering for denoising, binarization, thresholding, normalization, then GLCM texture features and region/contour segmentation.
- NL2SQL systems catalog: SQLizer, SEQ2TREE, SQLNet, Seq2SQL, DBPal, Neural Semantic Parser (NSP) for translating natural-language queries to SQL with WHERE/JOIN clause generation.
- STRIDE threat-modeling reference model plus risk assessment, asset identification, attack detection, attack-path modeling, and threat analysis as the threat-management workflow (Ch31).
- Ensemble emotion-detection patterns: Naive Bayes + Maximum Entropy with bagging/boosting on ISEAR/Affective-text, 3D-CNN with bagging/stacking and grid search, MFCC audio features, LSTM/Nested-LSTM/Bi-LSTM on Twitter text.

## Memorable
- Ch25 reports the APEML ensemble model reaching 99.99% accuracy detecting the top-12 attack types across six CIC datasets, with 10 enumerated mitigation strategies including Attack Surface Reduction (ASR) and Exploit Guard.
- Six CIC/security datasets named in the zero-day chapter: CIC-MalMem-2022, CIC-Bell-DNS 2021, CIC-Darknet2020, CICDDoS2019, CSE-CIC-IDS2018, and ISOT-2020, plus NSL-KDD and CICIDS18 elsewhere.
- Cloud-breach roll call used as evidence: AWS S3 exposure, Azure Cosmos DB, LockBit ransomware vs Accenture, the Kaseya supply-chain attack, Cognyte, and KA-SAT (tied to Russia's invasion of Ukraine); WannaCry and the Parity smart-contract flaw also cited.
- Nested LSTM hit 99.167% accuracy classifying seven emotions (anger, fear, joy, love, sadness, surprise, thankfulness) on Twitter-API data, beating plain LSTM and SVM+TF-IDF (Ch28).
- Ch24 critiques CVSS directly: a single severity score is inadequate for prioritization, motivating the 13-criteria AHP pairwise-comparison approach with consistency ratio validation.
- Maritime chapter (Ch30) claims maritime cyber-attacks rose 900% in three years and that 49% of commercial seamen have sailed a vessel hit by a cyberattack while 45% reported only a basic firewall as their sole defense.
- Blockchain+NLP chapter (Ch27) cites the blockchain+AI market at a 25.3% CAGR (2020-2025) surpassing $703 million, proposing smart contracts, tokenization, decentralized storage, consensus, and interoperability as integration solutions.
- Drebin is the recurring Android-malware benchmark dataset; CANDYMAN and FCSCNN (Feature Centralized Siamese CNN) are named detection approaches (Ch5).
- spaCy is cited with 680k word vectors and BERT-Large constraints (512 token / 16 limits) in the NL2SQL and rumor chapters.
- Lead editor Romil Rawat's bio: research grants from the US, Germany, Italy, and the UK; research focus on dark-web crime analysis and tracing illicit anonymous cyber-terrorism content.
- STRIDE model and Zotero/Mendeley/EndNote plus SPSS/Tableau/Excel are the named tooling in the research-methodology closing chapter (Ch31).
- Emotion-from-physiology study used LDA, CART, SOM, and SVM on EDA/ECG/PPG/skin-temperature signals from 200 college students, with SVM the top performer.

## Curriculum fit
For a security-research reading list this book is a mixed but worthwhile data point. The directly useful security content is concentrated in four chapters: Ch23 (CSP security comparison grounded in real breaches and the shared-responsibility model), Ch24 (AHP vulnerability prioritization with an explicit, well-argued critique of relying on CVSS alone, useful when you build your own scoring like VisorScuba), Ch25 (ensemble-ML zero-day detection methodology and the six CIC/ISOT dataset roster, a clean reference for benchmark selection), and Ch26 (GNN rumor detection fusing BERT/Word2Vec over propagation graphs). The IoT-IDS and Android-malware chapters add a survey-level map of detection techniques. For the creativity and leadership angles the fit is thin: there is no leadership or org content, and "creativity" appears only as the editors' generic teaching aspiration. For agentic-AI research the book predates and ignores agentic systems entirely; its NLP is classical (rule/statistical/DL pipelines, NL2SQL, sentiment) with no agent, tool-use, or autonomy framing. Net: harvest the AHP-vs-CVSS argument, the breach table, and the dataset rosters as citable primary references; treat the rest as a literature-survey index rather than a source of novel method. It pairs well as a contrast piece against modern agentic-AI security work, showing the pre-agent applied-ML-security baseline. One caution for the curriculum: many chapters are review-heavy with thin original evaluation, and several reported accuracy figures (99.99%, 99.167%) are presented without the verification rigor your own methodology demands, so cite the framing, not the numbers, as findings.
