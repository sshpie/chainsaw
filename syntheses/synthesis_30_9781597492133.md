## One-liner

A tool-by-tool field manual that walks a penetration tester through the full engagement lifecycle, from reconnaissance to forensics, using the BackTrack 2 Linux live CD and its bundled open-source tools.

## Thesis

Effective, legal, and repeatable penetration testing is achieved not by owning expensive commercial scanners but by mastering a methodical, phase-based process (recon to enumeration to exploitation to reporting) executed with freely available open-source tools, almost all of which ship pre-packaged on the BackTrack 2 live distribution. The book argues that understanding WHY each tool works (the underlying technology) matters more than memorizing switches, and that discipline (rules of engagement, verification, restraint, evidence handling, safe lab isolation) is what separates a professional assessment from reckless hacking.

## Core ideas

1. Reconnaissance is a reiterative four-phase loop, not a single step: Intelligence Gathering (learn about the target org), Footprinting (find DNS/IP details), Verification (confirm data accuracy), and Vitality (confirm targets are alive/reachable), feeding back into each other.
2. The central task of recon is mapping the 'real-world target' to the 'cyberworld' by producing the set of IP addresses that are both REACHABLE and RELEVANT (relevance, not authorization, is the analytical filter; authorization is a separate legal gate).
3. BackTrack 2 (a SLAX-based live Linux CD using compressed .lzm modules) is the unifying platform: nearly every tool in the book ships on it, so 'owning this book' gives a reader most of what professional pen-testers actually use.
4. Auth-on-default mindset for databases: SQL Server's sa account, mixed-mode auth, and xp_cmdshell, plus Oracle's TNS listener (1521) with default accounts (SYS/SYSTEM/SCOTT/DBSNMP) are the recurring footholds; default-credential tables are a primary attack surface.
5. Wireless security has progressively collapsed: WEP (FMS weak-IV, then chopchop unique-IV, then the PTW attack needing as few as 40,000-85,000 packets) and WPA-PSK (offline dictionary attack on the 4-way EAPOL handshake, accelerated 1000x by precomputed hash tables) are all crackable; only WPA-RADIUS has no known attack.
6. Network devices are high-value because controlling a router/switch can mean controlling the whole network; the dominant weakness is configuration error (default SNMP community strings like 'public'/'private', weak Cisco type-7 password encryption) rather than software bugs.
7. Verification and reading source before running are load-bearing discipline: the author manually fixed cge.pl because it only matched '200 ok' not '200 OK', and warns 'If you like your system security, you will never run a binary-only exploit!'
8. Forensics has become part of penetration testing: BackTrack jumped from 4 forensic tools (Auditor) to 13, signaling that incident analysis and evidence handling are now core skills, with the cardinal rule of source-disk read-only acquisition (bt nohd) and MD5/SHA1 hash verification.
9. A penetration test lab must be physically and logically isolated, labeled, and sanitized because the work handles biohazard-like malware and customer-sensitive findings; the Morris worm is the cautionary tale for why you 'should have tried it on a simulator first.'
10. Methodology over instinct: any formal framework (OSSTMM, NIST SP 800-42, ISSAF/PTF) is better than none; OSSTMM gives expected results but no tools (forcing skill growth), while ISSAF's PTF gives step-by-step commands (faster start but risks shallow tool knowledge).
11. Open-source tools build deeper skill than commercial tools precisely because they are not fully automated; the trade-off is time and lack of vendor support, but they give the attacker's perspective that point-and-click commercial scanners hide.
12. Every level of access must be parlayed upward: cracked router-config passwords get reused on other services, a wireless foothold becomes a pivot to the SQL Server, and an intern's weak SSH login (bbanter/bbanter) leads to the senior sysadmin account.

## Techniques and methods

- Nmap scan-type selection: -sS SYN, -sT connect, -sF FIN, -sX Xmas, -sN NULL, -sA ACK, -sI idle/zombie, -sU UDP, plus -sV version detection and -O OS fingerprinting, with timing templates T0 (Paranoid) through T5 (Insane)
- DNS reconnaissance: attempting AXFR zone transfers, reverse-DNS brute forcing with bf-dns.pl (using netenum to enumerate a range), and recognizing that forward and reverse zones are separate databases
- Link/footprint analysis with BiLE (Bi-directional Link Extractor) and its weighting algorithm, TLD expansion, and domain-name expansion to find related hosts
- SQL injection by example: ' OR 1=1-- to bypass auth, command injection via 127.0.0.1 | ipconfig, and using squeeza's three return channels (DNS requests, database error messages, and a timing channel) for blind data extraction
- Oracle privilege escalation via the glogin.sql technique: manipulating the lsnrctl log file to inject 'create user attacker identified by password; grant dba to password;'
- Writing a Perl buffer-overflow fuzzer (sendraw function) against the eEye IIS .printer overflow, locating EBP at 268 bytes and overwriting EIP at 272 bytes with 42424242 (BBBB)
- Full WEP crack chain with the aircrack-ng suite: airmon-ng (monitor mode) -> airodump-ng (capture IVs) -> aireplay-ng fake auth (-1), fragmentation (-5) or chopchop (-4) to get PRGA -> packetforge-ng to craft an ARP packet -> aireplay-ng ARP replay (-2/-3) to inject -> aircrack-ng (FMS/KoreK or PTW -z)
- WPA-PSK crack: capture the 4-way EAPOL handshake (forcing it via aireplay-ng deauth -0), then run CoWPAtty (cowpatty -f wordlist -r dump -s SSID) or use genpmk precomputed hash tables (-d) for ~60,000 passphrases/sec
- MAC-filter bypass with macchanger (e.g., macchanger -m 00:DE:AD:BE:EF:00 ath0) after enumerating allowed client MACs in Kismet's client view
- Router compromise: onesixtyone for SNMP community brute force, snmpwalk/snmpset to walk the MIB and force the running-config to a TFTP server, Hydra (-t 2) to brute-force Cisco Telnet and the enable password, and IRPAS hsrp to hijack the HSRP virtual IP
- Forensically sound imaging: boot with the bt nohd cheat code, mount source read-only (mount -o ro), then dd if=/dev/hda bs=512 conv=sync,noerror | split -b 640m, or dcfldd with hashwindow=0, or pipe over the network with netcat; verify with md5sum (chance of collision 1 in 2^128)
- File carving and artifact recovery: Foremost (foremost -t jpeg -i image) and Magicrescue (magic-byte recipes) to reconstruct files by header/footer, pasco to parse Internet Explorer index.dat browsing history, Vinetto to extract thumbs.db images, and memfetch to dump a live process's RAM

## Memorable

- Opening hook: 'So, you want to hack something? First, you have to find it!'
- Robert Graham (Hackers & Painters), quoted: 'Great hackers also generally insist on using open source software... Good hackers insist on control.'
- Case study credentials harvested intact: WEP key cracked to '2D:F6:EF:37:36:B4:47:BB:07:55:90:38:D2' after ~50,000 IVs; WPA-PSK passphrase recovered as 'Syngress' after a 20-minute CoWPAtty dictionary run
- PTW attack stats: WEP key recoverable with 50% probability at 40,000 packets and 95% at 85,000 packets, in three to four minutes (vs millions of packets for the original FMS weak-IV attack)
- Cisco Telnet brute force: Hydra guessed the password 'p4ssw0rd' in only 22 seconds; the Buenobank case dumps a full router config exposing type-7 hashes and SNMP community 'bbrtr1 RW'
- Bluetooth barrier-to-entry: no commercial Bluetooth sniffer costs under $3,500 and most run $10,000-$25,000, yet a consumer dongle can be reflashed into a sniffer; an estimated 1+ billion Bluetooth devices are in use
- The De-ICE.net 1.100 LiveCD walkthrough: the intern 'Bob Banter' uses login 'bbanter' with password 'bbanter' (login==password), giving the first foothold that pivots to the senior sysadmin
- Morris worm cautionary tale: ~$10M-$100M in damage, 400 hours community service and >$10,000 in fines; Michael Rabin's verdict that Morris 'should have tried it on a simulator first'
- Market facts cited: ~70% of internet servers are web servers (Netcraft), Apache+IIS hold ~90% combined share, and Oracle held 44.4% of the database market in 2006; Nessus (released 1998 by Renaud Deraison) was voted #1 security tool in 2003 and 2006
- Operational restraint framing: the book treats malware like a biohazard, demanding labeled hazardous-waste bins, CD shredding, and DoD 5220.22-M disk sanitization before any lab gear rejoins a production network
- Tool provenance: dcfldd was written by Nick Harbour at the DoD Defense Cyber Forensics Lab; Foremost by Jesse Kornblum at the DoD Cyber Crime Center; Autopsy/Sleuth Kit by Brian Carrier (originally an @stake commercial product)
- The author's own war story: setting up a home wireless lab he discovered the local police department used the identical (unencrypted) wireless config, nearly hacking the police by accident

## Curriculum fit

Strong fit as a hands-on practicum/lab text in an offensive-security or ethical-hacking course, bridging conceptual security theory and real tool execution. Best used after a networking-fundamentals and a security-concepts course, since it assumes TCP/IP, DNS, and OS literacy. Its phase-based structure maps cleanly onto pen-testing certification tracks (the BackTrack lineage is the direct ancestor of Kali Linux), and Chapter 9's framework survey (OSSTMM, NIST SP 800-42, ISSAF) plus the De-ICE.net LiveCDs give ready-made lab assignments. Caveat for any modern curriculum: this is a 2007 snapshot tied to BackTrack 2; specific versions, URLs, and some tools are dated (WEP is essentially extinct, Kali replaced BackTrack, modern web frameworks changed the SQLi/XSS surface), so it should be taught for methodology and tool-thinking rather than current command syntax. The forensics and lab-safety/legal-discipline chapters age best and remain directly relevant to incident-response and lab-ops modules.
