# 41. Learn Mistral AI

**ISBN** 9781835888643  |  **Lobe** ai-agentic

> A build-to-learn lab manual for standing up Mistral inference end to end (local Ollama to AWS Bedrock to GCP Vertex), with the parameter-level decoding control, embeddings/RAG plumbing, ReAct agents, and Codestral security-review prompts you reach for when you need a second open-weight LLM stack that you can run offline and audit.

## Reach for this when

- You want a non-OpenAI/non-Anthropic LLM in the loop, especially an open-weight one you can run locally (Ollama port 11434, Mistral 8B/Nemo) for offline or privacy-sensitive work like processing firewall logs you cannot ship to a cloud API
- You are building a tool that classifies or summarizes from natural language and need the exact decoding knobs (temperature=0 deterministic for code/security, 0.7 for creative; top_k/top_p/min_p; repetition/presence/frequency penalties) rather than guessing why output drifts
- You need a multi-cloud inference fallback and want the concrete swap recipe: same model behind Ollama /api/generate, Bedrock boto3 invoke_model, or Vertex mistralai[gcp] SDK, reusing one chat UI by mimicking the /api/generate contract
- You are scaffolding a RAG pipeline and naive retrieval is the weak link; you want the four query-rewriting strategies (multi-query, atomic sub-queries, step-back generification, get_unique_union dedup)
- You want an LLM as a security co-analyst over raw artifacts: firewall logs, Terraform security groups, JDBC concatenation, PHP echo, with a role-task-format prompt that returns actionable verdicts (block this IP, prepared statements, htmlspecialchars)
- You need to fingerprint or attribute exposed Mistral infra and want the exact backend tells: Ollama 11434, Bedrock modelId mistral.mistral-small-2402-v1:0, Vertex Model Garden endpoints at {LOCATION}-aiplatform.googleapis.com

## Principles

- Build-to-learn: a parameter stops being a magic knob once you implement softmax and sampling from scratch; reach here when you need decoding intuition, not a config copy-paste
- Same model, three deployment tiers (local / Bedrock / Vertex); architect for backend-swap by isolating the inference call behind a stable contract
- Embeddings turn meaning into geometry: mistral-embed is 1024-dim, and the same vectors power search, classification, recommendations, and RAG; visualize with PCA for the global picture and t-SNE for local clusters
- RAG is indexing + retrieval + generation, and retrieval is the failure point; fix it with query rewriting before blaming the model
- Prompt as structured contract: who the model is, the task list, the response format; the same recipe drives security review, RAG generation, and summarization
- Cost and least-privilege are first-class: Vertex workshop budgeted under $5, Codestral free trial is exactly 50 requests, and the book grants AdministratorAccess for convenience while flagging it as bad production practice

## Moves

- Run a model fully offline: Ollama on 11434, author a Modelfile (FROM + SYSTEM moderation prompt), serve via Open WebUI in Docker with user governance, integrate Obsidian BMO for note-grounded chat; use this for log triage you cannot send to a hosted API
- Tune decoding deliberately: temperature=0 for code and security analysis (deterministic), 0.7 for creative; prune the distribution with top_k/top_p/min_p; damp loops with repetition/presence/frequency penalties
- Stand up semantic search: mistral-embed (1024-dim) -> scipy.spatial.distance cosine -> Pinecone create/upsert/query, then PCA + t-SNE + seaborn heatmap to make similarity legible
- Build a multi-agent service: one shared ReAct prompt in LangChain ChatMistralAI driving a safe calculator tool, a web search tool, and role-specific agents routed by a controller; or wire the same flow no-code in n8n (Yahoo Finance + Google News RSS -> Code nodes for dedup/ATR/z-scores -> Mistral -> Telegram)
- Harden RAG retrieval: WebBaseLoader -> RecursiveCharacterTextSplitter (300/50 text, 2000/200 code) -> MistralAIEmbeddings -> Pinecone/Chroma -> retriever, traced in LangSmith, then layer multi-query + atomic sub-query + step-back with get_unique_union dedup
- Code-RAG over a real repo: GitPython clone -> GenericLoader + LanguageParser (1,530 files into 2,411 chunks) -> Chroma -> ConversationalRetrievalChain with MMR k=8; then Codestral in VS Code via Continue (Cmd+I generate, Cmd+L context, FiM completion)
- Run Mistral as security reviewer with role-task-format prompts: flag 0.0.0.0/0 ingress and Action:* Resource:* IAM in Terraform, rewrite JDBC concatenation to prepared statements, convert PHP echo to htmlspecialchars, triage DDoS/port-scan/brute-force/SYN-flood log patterns
- Deploy managed: Bedrock boto3 list_foundation_models -> invoke_model on mistral.mistral-small-2402-v1:0 with streaming StreamingBody parse, CloudTrail filter bedrock.amazonaws.com; Vertex Model Garden enable Mistral Small 3.1, gcloud auth print-access-token, mistralai_gcp client.chat.complete and client.chat.stream

## Watch out

- Vendor- and version-coupled: exact model IDs (mistral-small-2402-v1:0, Pixtral Large 25.02), SDK versions, and console screenshots date fast; treat every ID and endpoint as a snapshot to re-verify, not a current fact
- It grants AdministratorAccess and AmazonBedrockFullAccess for workshop convenience while only verbally flagging least-privilege; do not copy these IAM grants into anything real, the book itself calls it bad practice
- Codestral security review is single-file and pattern-level: it catches 0.0.0.0/0, JDBC concatenation, and PHP echo, but it cannot reason across files or confirm exploitability; pair every model verdict with a real validator (#42, #12, #17, #15) before calling it a finding, never assert exploitable unverified
- Theory chapters (Ch1, parts of 3-6) are thin; the math (Verizon DBIR stats, distance metrics) is illustrative, not authoritative; go to primary sources for numbers you will cite
- Self-shipped-fast tells: it misspells its own vision model ('Pixtraill'/'Pixtrail') and the GitHub URL drifts between Learn-Mistral and Learn-Mistral-7B; minor, but a signal to double-check repo paths and copy-pasted commands
- RAG dedup and query-rewriting strategies add latency and token cost per query; the four-strategy stack is a quality lever, not a default, and the book does not benchmark when the extra calls actually beat naive retrieval
